# HATERCAT website

A static, responsive landing page inspired by the editorial/minimal structure of the reference LOVERCAT site, with original HATERCAT copy and the generated cat artwork.

## Files
- `index.html` — page structure
- `style.css` — responsive styling/animations
- `assets/hatercat.png` — HATERCAT artwork

## Before launch
1. Replace the Pump.fun link in `index.html` with the actual HATERCAT token URL after launch.
2. Replace the X/Twitter link with the project's actual account.
3. Replace the Dexscreener link and chart placeholder with the actual token pair.
4. Add Telegram/Discord links if desired.

## Deploy
This is a static site and can be deployed to Vercel, Netlify, Cloudflare Pages, GitHub Pages, etc.

For a custom domain, buy/register a domain (for example `hatercat.xyz` if available) and point its DNS records to the hosting provider.
